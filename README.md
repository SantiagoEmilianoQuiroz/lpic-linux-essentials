# 🐧 LPIC Linux Essetials

Documentacion, ejercicios y recursos para la certificacion LPIC Linux Essetials

## 📝 Temario

- **Tema 1: La comunidad Linux y una carrera en el codigo abierto:**
    - Los sistemas operativos populares y la evolucion de Linux
    - Principales  aplicaciones de codigo abierto
    - Software de codigo abierto y las licencias
    - Destrezas de TIC y trabajo con Linux
- **Tema 2: Encontrando el camino en un sistema Linux:**
    - Aspectos basicos de la linea de comandos
    - Uso de la linea de comandos para obtener ayuda
    - Uso de directorios y listado de archivos
    - Crear, mover y borrar archivos
- **Tema 3: El poder de la linea de comandos:**
    - Archivar ficheros desde la linea de comandos
    - Buscar y extraer datos de los ficheros
    - Crear un script a partir de una serie de comandos
- **Tema 4: El sistema operativo Linux:**
    - La eleccion del sistema operativo
    - Conocer el hardware del ordenador
    - Donde los datos se almacenan
    - Tu ordenador en la red
- **Tema 5: Seguridad y sistema de permisos de archivos:**
    - Seguridad basica e identificacion de tipos de usuarios
    - Creating Users and Groups
    - Gestion de los permisos y la propiedad de los archivos
    - Directorios y archivos especiales

## 🧪 Laboratorio

Pequeño entorno de administracion Linux que simula el trabajo real de un administrador Linux junior aplicando todos los conocimientos adquiridos al preparar la certificacion LPIC Linux Essentials

**Objetivo del laboratorio:**
- Administrar un servidor Linux para dar soporte a usuarios 
- Gestionar permisos 
- Mantener archivos
- Instalar software
- Controlar procesos
- Monitorizar el sistema y resolver incidencias
